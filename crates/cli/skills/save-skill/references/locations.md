# Where other tools keep skills

From the skills CLI's list of agents (github.com/vercel-labs/skills). `~` is the user's home folder. Look at these paths, not around them.

## Shared by many tools

- `~/.agents/skills`: Codex, Cline, Warp, Zed, Pi, and others. The folder the skills CLI installs into first, with links from the tools' own folders.
- `~/.config/agents/skills`: Amp, Replit
- `.agents/skills` in a project: the same tools, for one project
