# Languages

The apps speak English and Simplified Chinese, and the key of every string is its English text, so a string with no translation reads as written.

- **Phone** (`mobile/src/i18n`): `t("{name} is working…", { name })` over `zh.ts`, in the language picked in Settings › App Language (`app_lang` in the phone's prefs), else the phone's from `expo-localization` (English where there is no native module, as under `bun test`). A pick changes the words in place: every component that says words calls `useLanguage()`, which renders it again, and a memo that holds words (the transcript's rows) lists the language among its dependencies, so the navigators and a presented sheet stay put. `tc("Open", "browser")` is one English word that means two things, the key `Open|browser`, as the desktop app's `Lc` key is. `t()` is called while rendering, never at module load. `app.config.ts` carries the permission prompts and locales that make the app offer its languages in iOS Settings; the locale files (`locales/*.json`) keep their Info.plist strings under `ios`, since Expo writes a locale's other keys into Android's string resources, where a release build's lint refuses a translation the default locale lacks. The mobile build uses the DEV-tagged launcher, adaptive, splash, favicon, and pairing-screen artwork in the local dev loop and EAS development profile, and the untagged set otherwise; the same config feeds the native assets and splash plugin for that build variant. `src/ui/format.ts` words times and dates in Chinese from small tables. A row's value that offers choices is usually a `MenuAccessory` (`src/ui/forms.tsx`): a SwiftUI `Menu` on iOS and a Material 3 Jetpack Compose dropdown on Android, with a checkmark on the choice in force. The Model row is a `SheetPicker` bottom sheet when the list can be long.
- **Desktop app** (`desktop/l10n`): `L("New Bot…")`, `L("%@ is working…", name)`, and `Lc("Pairing", "device state")`, over `zh.go`. Settings › General › App Language saves the pick in the app's preferences, and the views draw their next frame in it, so the windows, their sizes, and the selection stay; the menu bars, the tray menu, and the window titles take the new words at once.
- **What the CLI words stays as it arrives**, with one exception: a routine's `schedule_text` ("Weekdays at 9:00 AM") is rebuilt in Chinese by the desktop app's `model/format.go` and `scheduleText` on the phone. Notices, permission summaries, the demo data, and a workflow's name, outcome, and questions from the marketplace index are English.
- `bun run l10n` (`scripts/l10n.ts`) reads every `L("…")`, `Lc("…", "…")`, and `t("…")` in the two apps' sources and reports a string with no translation, a translation nothing uses, and a translation that takes different values than its key; `--merge <file.json>…` adds `{ "English": "中文" }` files to the tables first.
