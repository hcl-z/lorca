# Phone releases and updates

Both phone builds are files of this repo's GitHub releases tagged `mobile-vX.Y.Z`, made by `scripts/release-ios.ts` and `scripts/release-android.ts` here or in `.github/workflows/release-mobile.yml` ([docs/releasing-mobile.md](../releasing-mobile.md)). The iOS build is an unsigned `.ipa`, archived with code signing off: a sideloading tool signs it with the user's own Apple ID, nothing updates it but installing a newer file, and, without the App Store build's entitlements, remote pushes do not reach it. The Android APK is signed with the release key in the `ANDROID_KEYSTORE` secret. The version is `version` in `app.config.ts`, and Android's versionCode is made from it (1.2.3 is 1002003).

The Android release build updates itself (`src/core/updates.ts`): once a day, at launch or back in the foreground, it reads the `mobile-v` tags through the GitHub API, since the repo's latest release is the CLI's, takes the newest published release newer than itself, and offers it in an alert with the release's notes (Install Update, Remind Me Later, Skip This Version); Settings › Updates checks at once or installs what a check found, shows the download's progress, and holds the switch for the daily check, with the choices in `prefs.ts`.

Install Update, from either, opens a Material dialog (`src/ui/UpdateProgress.tsx`) with the download's percent and a progress bar, indeterminate once the installer has the APK, until the app restarts; Hide puts it away while the download goes on, and a failed download or install is said in an alert. `Updater.kt` in the native module downloads the APK, checks it against the size and SHA-256 GitHub lists for the asset and that it is this app and newer, and commits it to a `PackageInstaller` session, which installs only an APK signed with the installed app's key and then stops the app. It asks for no confirmation from Android 12 (`UPDATE_PACKAGES_WITHOUT_USER_ACTION`) once the user has let Lorca install apps; otherwise the installer's confirmation shows, from the foreground. Lorca Dev never updates.
