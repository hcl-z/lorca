# The island

A window at the top of every display says what the bots are doing when the main window is out of sight, following OpenBot's Dynamic Island (`packages/ui/src/features/dynamic-island`). Its states, most urgent first: a question waiting for the user, a result from the last eight seconds, a bot or coding agent at work, else idle. Each display gets a transparent 614×380 canvas on its top edge, so a panel opens inside it instead of resizing the window; the block itself is a 268×32 capsule (136 wide while idle, radius 16) that grows 32×8 under the pointer, and a 420-wide, 24-radius panel with a 14/20/20 inset while something waits. A state change morphs the block over 420 ms and the new content fades in from a little lower (MyGo's `AnimateTo` and `Transition`), option rows arrive in a stagger, and a row or button fades its fill over 120 ms and presses at 98% (`AnimateColor`, `AnimatePose`). The capsule is the app's mark and an unread count when idle, an avatar, the agent's name, and a Working chip at work; a result is the avatar, the bot's name, and the last line it said, and a click opens its chat. The panel leads with the bot's avatar, name, and a chip for what it needs (asks, needs approval, needs you), then the question or, for a permission, the command behind a warning bar; a bot's `ask_user` options are numbered rows answered in place (`Store.AnswerAsk`), a coding agent's permission puts the same decisions as its card in the last row with Allow once in ink (`Store.AnswerPermission`), a form the island cannot fill opens the chat, and the row counts the requests behind this one. The pointer turns clicks on and off: a 120 ms poll reads `Screen.CursorScreenPoint`, grows the capsule when the pointer is over the block, and calls `SetIgnoreMouseEvents` so a click outside it reaches the app below (MyGo cannot forward moves to an ignored window, so the island polls). Under the pointer a working capsule opens into one 44-tall row per agent or bot at work, its chat named under it, and a click on a row opens that chat. A click on the capsule opens Lorca, or the chat of the question the header names, and View › Island (⌘⇧I, registered with `GlobalShortcut` so it works from another app too) opens the first waiting question, or Lorca when none waits. On macOS MyGo's window stops at the floating level under the menu bar, so `island_darwin.go` raises it with objc to `NSStatusWindowLevel`, drops its title bar, keeps it through a Space switch and a full-screen app, and swaps its class to `NSPanel` with the nonactivating style, so a click answers without taking the keyboard from what the user is typing in; the other platforms build the same code without the window. `Screen.OnDisplaysChanged` rebuilds a display's window. General › Island holds its settings, all on to start with: the island itself (`ShowsIsland`), one on every display or the main one alone (`IslandAllDisplays`), the idle capsule (`IslandIdleVisible`), growth under the pointer (`IslandHoverGrow`), the compact width as Small, Regular, or Large (`IslandSize`), and how long a result stays (`IslandResultSeconds`, 8 by default). The section is not shown off macOS.
