A bot can hand a coding job to **Claude Code**, **Codex**, or another coding agent that speaks the Agent Client Protocol (Gemini CLI, OpenCode, Kimi Code, GitHub Copilot, Cursor, Kiro, pi) on its Runner and supervise it: the agent works on its own, the bot reads what it does, sends it follow-ups, and tells you when it is done, with the diff and the pull request.

## Start one

Ask the bot:

> Have Claude Code fix the flaky login test in ~/dev/app, and open a pull request.

The Runner needs the agent installed, as your terminal finds it; Claude Code, Codex, and pi also need `npx`, which runs the adapter that connects them. pi runs commands without asking first, so Auto-review sees none of them; name it only for work you would let it do unwatched. Without a preference the bot uses Claude Code, else Codex; the others start when you name them. Starting one needs **Shell commands** in the bot's [Access](/docs/access), and goes through [Auto-review](/docs/auto-review): when it asks, the card reads "Developer wants to start Claude Code on Workbench" with **Allow once**, **Always allow**, and **Deny**.

In a git repository the agent never works in your checkout. It gets a worktree of its own in Lorca's folder, on a new branch made from the repository's current commit, named after the job. A later job can go on in the same branch. A folder that isn't a repository is worked in as it is.

## What it may do

Every command the agent runs goes through the bot's Access and Auto-review, as the bot's own commands do. Commands that only read, and work inside its worktree, run at once; a push or a deploy is weighed against what you asked for. When Auto-review asks, the agent's card reads "Claude Code wants to run a command" with the command and the same answers, from any of your devices.

A bot can give an agent [secrets](/docs/secrets) it saved for commands, such as `NPM_TOKEN` to publish a package.

## The card

The agent's card stays in the chat: its name, what it was asked, how it stands (Starting, Working, Quiet, Done, Ended, Failed, or Stopped) with its branch, then its model, how hard it thinks, its mode, and how much of its context it has used, and while it works its latest lines. Click what it works on to read its whole transcript. **Stop** on the card ends it.

For a large or unclear change your bot can have the agent plan first: it works out the plan in its plan mode and asks before it changes anything, and you or Auto-review approve the plan on its card. Your bot can also pick the agent's model and how hard it thinks, at the start or later while the agent runs, and so can you: on the desktop the card shows them as two pop-ups, and the conversation carries on with the new choice. An agent that has no such choice says what it offers.

An agent can also ask you a question while it works, such as which database to use. The question comes into the chat as a card of its own, "Claude Code asks", with its choices to click, a field for your own words, or yes and no, and the agent's card says it is waiting for you. A single choice sends as soon as you pick it; a longer form sends with **Submit**, and **Decline** lets the agent go on without an answer. Answer from any of your devices. Your bot hears the question too and may answer it when what you told it settles the matter; whoever answers first wins, and the card then shows who answered and what. A question nobody answers in ten minutes is cancelled, and the agent goes on without it.

On the desktop app, an agent at work also gets a small window that floats over the app. Drag it by its title wherever you like; **Close** puts it away until the agent works again. Click it to fill the app window with the agent: its whole transcript, **Stop**, and the card of anything it asks. Press Escape to bring the window back.

## When it is done

When the agent finishes, Lorca posts its work in the chat as the bot's [outputs](/docs/chats#outputs): the diff of everything it changed, and the pull request it opened. Then the bot reads what the agent said and tells you, or sends it a follow-up. An agent that goes ten minutes without anything new, or that exits, wakes the bot too.

**Stop** in the chat stops the chat's coding agents along with the bot's work. Quitting Lorca stops the agents. The agent's run time counts toward the [limits](/docs/limits) of the turn that started it.
