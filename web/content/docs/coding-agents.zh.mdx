智能体可以把一项编程工作交给它 Runner 上的 **Claude Code**、**Codex** 或其他支持智能体客户端协议（Agent Client Protocol）的编程智能体（Gemini CLI、OpenCode、Kimi Code、GitHub Copilot、Cursor、Kiro、pi），并负责监督：编程智能体独立干活，你的智能体读它的进展、给它补充指示，做完后把 diff 和 pull request 告诉你。

## 启动

对智能体说：

> 让 Claude Code 修好 ~/dev/app 里那个时好时坏的登录测试，然后开一个 pull request。

Runner 上要装有这个编程智能体，并且在终端里能找到它；Claude Code、Codex 和 pi 还需要 `npx`，用来运行连接它们的适配器。pi 执行命令前不会先询问，所以自动审查看不到它的任何命令；只在你放心让它无人看管去做的工作里点名使用它。没有指定时，优先用 Claude Code，没有再用 Codex，其他的要点名才会启动。启动需要智能体的[访问权限](/zh/docs/access)里允许 **Shell 命令**，并经过[自动审查](/zh/docs/auto-review)：需要问你时，卡片会显示“Developer 想要在 Workbench 上启动 Claude Code”，下面是 **允许一次**、**始终允许** 和 **拒绝**。

在 git 仓库里，编程智能体从不直接改你的工作副本。它会在 Lorca 的文件夹里得到一个自己的 worktree，基于仓库当前的提交新建一个分支，分支名取自这项工作。之后的工作可以在同一个分支上继续。不是仓库的文件夹，就直接在里面工作。

## 它能做什么

编程智能体运行的每条命令，都和你的智能体自己的命令一样，要经过智能体的访问权限和自动审查。只读取的命令、以及在它自己 worktree 里的工作会直接运行；push 或部署这类操作，会对照你最初的要求来判断。自动审查需要问你时，编程智能体的卡片会显示“Claude Code 想要运行命令”，附上命令和同样的几个选项，任何一台设备上都能回答。

智能体可以把它为命令保存的[密钥](/zh/docs/secrets)交给编程智能体使用，比如发布软件包用的 `NPM_TOKEN`。

## 卡片

编程智能体的卡片会一直留在聊天里：它的名字、交给它的任务、当前状态（正在启动、正在工作、暂无进展、完成、已结束、失败或已停止）和所在分支，接着是它的模型、思考强度、模式和已用的上下文；工作时还会显示最新的几行输出。点它正在做的内容，可以读完整记录。卡片上的 **停止** 会结束它。

遇到大的或不明确的改动，你的智能体可以让编程智能体先做规划：它在规划模式里想好方案，动手改之前先来问，你或自动审查在卡片上批准这个方案。你的智能体也可以指定编程智能体用的模型和思考的力度，启动时指定，或者在它运行中改；你自己也可以改：桌面端的卡片上有两个下拉菜单，换了之后对话接着往下走。没有这个选项的编程智能体会说明它能选什么。

编程智能体工作时也可以向你提问，比如用哪种数据库。问题会作为一张单独的卡片出现在聊天里，标题是“Claude Code 提问”，带有可点选的选项、填写自己答案的输入框或“是/否”，编程智能体的卡片也会显示它正在等你回答。只有一个选择时，点一下就会发送；表单较长时点 **提交** 发送，点 **拒绝回答** 则让编程智能体在没有答复的情况下继续。任何一台设备上都能回答。你的智能体也会收到这个问题，只有你说过的话已经能定下答案时才会替你回答；谁先答就听谁的，卡片随后会显示是谁回答的、答了什么。十分钟没人回答，这个问题会被取消，编程智能体继续往下做。

在桌面应用里，正在工作的编程智能体还会有一个浮在应用上方的小窗口。按住标题可以把它拖到任何位置，**关闭** 会把它收起，直到这个编程智能体再次开始工作。点击小窗口，会让这个编程智能体铺满应用窗口：完整记录、**停止**，以及它提问的卡片。按 Esc 回到小窗口。

## 做完之后

编程智能体完成后，Lorca 会把它的成果作为智能体的[输出](/zh/docs/chats#输出)发到聊天里：所有改动的 diff，以及它开的 pull request。然后智能体读完编程智能体说的话，向你汇报，或者再给它补充指示。编程智能体十分钟没有任何新进展，或者退出了，也会唤醒智能体。

聊天里的 **停止** 会连同智能体的工作一起停掉聊天里的编程智能体。退出 Lorca 会停止所有编程智能体。编程智能体的运行时间，计入启动它的那一轮的[上限](/zh/docs/limits)。
