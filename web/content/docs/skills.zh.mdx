**技能** 是写下来的做事方法：什么时候用、步骤，以及它需要的参考资料、脚本或其他文件。智能体每一轮都能看到它能用的各个技能的名称和描述，遇到匹配的任务时才读取完整内容，所以技能写得再长，用不到时也不占地方。

技能和 Claude Code、Codex、Cursor 用的是同一种格式：一个文件夹，里面有一个 `SKILL.md`。保存技能就是写这个文件夹，智能体从下一轮起就会用上。

## 技能在哪里

技能是智能体所在电脑上的文件夹：

| 给谁用 | 文件夹 |
| --- | --- |
| 这台电脑上的所有智能体 | `~/.lorca/skills/` |
| 某个智能体 | `~/.lorca/workspaces/<智能体 id>/skills/` |
| 某个群聊 | `~/.lorca/groups/<聊天 id>/skills/` |

智能体单聊检查器的 **技能** 部分列出它自己的技能，后面是所有智能体共用的技能，带一个地球图标；在任意一个智能体里修改或删除共用技能，对所有智能体都生效；群聊的检查器列出群聊的技能（手机上在聊天的详细信息里）。名称相同时，智能体自己的技能优先于群聊的和共用的。智能体和群聊的技能会同步到你的其他设备，智能体换到另一台电脑上运行时，技能也在那里。

每个智能体还内置了三个技能：`lorca` 让它去读这份文档，`write-skill` 说明怎么写技能，`save-skill` 把你在其他工具里已有的技能收进来。它们和共用技能列在一起，不能编辑。

## 让智能体来做

告诉智能体把它刚才的做法存成技能，或者告诉它你一直在同一点上纠正它。它会自己写好文件夹，默认存在它自己的技能里，除非你说要给群聊或所有智能体用；聊天里会告诉你它存了什么、存在哪里。

让它把你在 Claude Code、Cursor 或其他工具里的技能收进来，它会去这些工具用的文件夹里找（`~/.claude/skills`、`~/.agents/skills` 等），把找到的告诉你，再问你要收哪些，以及是移动并在原处留一个链接（这样原来的工具照样能用）、只移动，还是复制。

## 从技能商店添加

在桌面端，点智能体 **技能** 旁边的 **+**，或选择 **聊天 › 技能商店…**，为这个智能体添加技能；从群聊里打开则给整个群聊。要添加这台电脑上所有智能体共用的技能，点侧边栏顶部的 **+**，选择 **为所有智能体添加技能…**。

商店会在你输入时搜索 [skills.sh](https://skills.sh)（至少两个字母），也可以点它推荐的主题；每个技能会显示它来自哪个仓库、被安装过多少次，点它可以打开它的页面。也可以粘贴 skills.sh、ClawHub 或 GitHub 上某个技能的链接（`owner/repo`，仓库里有多个技能时用 `owner/repo@技能名` 指定一个）。点 **添加** 会复制技能的整个文件夹，下一轮起就会用上。**新建空白技能…** 则从头写一个。

商店里的技能是别人写的，添加后立刻生效，所以重要的场合请先打开读一遍。它的脚本只会通过智能体的命令运行，自动审查会像检查任何外来程序一样检查它们。商店通过你的电脑访问网站；如果你那里访问 skills.sh、ClawHub 或 GitHub 很慢，可以用环境变量 `LORCA_SKILLS_SH_URL`、`LORCA_CLAWHUB_URL`、`LORCA_GITHUB_API_URL`、`LORCA_GITHUB_RAW_URL` 和 `LORCA_GITHUB_ARCHIVE_URL` 让 CLI 走镜像。从 GitHub 只会下载技能自己的文件夹；环境里有 `GITHUB_TOKEN` 时可以突破 GitHub 每小时的访问次数限制。

## 写一个技能

选择 **聊天 › 新建技能…**，或在技能商店里点 **新建空白技能…**（手机上是 **添加技能 › 新建技能…**）。一个技能包括：

| 字段 | 含义 |
| --- | --- |
| **名称** | 简短的名字，写成英文短横线形式，比如 `weekly-report`。它就是文件夹的名字。 |
| **描述** | 它做什么、什么时候用。智能体靠这段话来判断。 |
| **指令** | 具体步骤。 |
| **示例** | 好的结果长什么样。保存时会成为指令里的一节。 |
| **参考资料** 和 **脚本** | 技能附带的文本文件，比如一份风格指南，或者智能体用自己的工具运行的脚本。 |

**保存** 会写好文件夹，智能体从下一轮开始就能用。看起来像密码或密钥的内容，保存时会被去掉。文件夹里的其他文件，比如图片或模板，会原样保留。你也可以直接编辑文件夹里的文件。

## 从聊天里存一个

智能体某件事做得正合你意、希望以后照做时，右键点按它的回复，选择 **存为技能…**。同一件事你已经纠正过它不止一次时，右键点按你自己的某条消息，选择 **存为长期指令…**。在手机上，用详细信息里的 **添加技能 › 从这个聊天中…**。

面板会列出聊天里最近的消息：勾选能体现这项工作的那几条；在群聊里，还要选这个技能是给整个群聊用，还是只给某个智能体用。**继续** 会让智能体的服务商根据这些消息写好技能，打开给你修改后保存。

你还可以在智能体的浏览器里亲手做一遍某个网站上的任务，教会它；见[录制工作流程](/zh/docs/browser#录制工作流程)。

## 删除与导出

技能菜单里的 **删除…** 会把它的文件夹移到同一个技能文件夹下的 `.trash` 里，保留 30 天。

**导出…** 会把技能存成它文件夹的 zip 压缩包，自己留着或交给别人（手机上通过共享面板），任何读取技能文件夹的工具都能用。压缩包里只有技能的文件，不包含你账号的任何信息。要连同技能分享整个智能体，见[分享智能体](/zh/docs/templates)。

智能体的[反馈](/zh/docs/feedback)可以建议修改技能的指令，由你接受或拒绝。
